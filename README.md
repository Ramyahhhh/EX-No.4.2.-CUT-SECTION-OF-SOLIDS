# EX No.4.2. CUT SECTION OF SOLIDS
## DATE: 5-11-26
## REG NO: 26017329
## NAME : M RAMYA

## AIM: 
To create a 3D solid model of a Goblet using the Revolve feature and generate its cut section view using Autodesk Fusion 360.

 

## HARDWARE AND SOFTWARE REQUIREMENTS:

• Software. Autodesk Fusion 360 (3D CAD/CAM modeling suite) with an active user account.
• Operating System. Microsoft Windows 10 (64-bit) operating system.
• Memory & Graphics. 16 GB RAM paired with integrated or dedicated graphics supporting 1 GB or more VRAM.
• Internet Connectivity. A stable broadband connection with at least 2.5 Mbps download and 500 Kbps upload speeds for cloud synchronization.
• Peripherals. A standard keyboard, a three-button scroll mouse, and a display monitor.
 

## PROCEDURE:
## STEP-1:
   Launch Autodesk Fusion 360, open a New Design file, and click the Create Sketch icon on the toolbar.
## STEP-2: 
  Select an appropriate reference plane (XY, YZ, or XZ) to begin sketching.
## STEP-3: 
   Open the Create dropdown menu and use 2D sketching tools (Line, Rectangle, Circle, Arc, Polygon, and Sketch Dimension) to draw the required profile.given sketch

![image](https://user-images.githubusercontent.com/113594316/198826239-a3d6ffd5-d409-46b0-ba88-3312e89e9834.png)

## STEP-4:
   Open the Modify dropdown menu and apply editing features (Fillet, Chamfer, Trim, Extend, Offset, and Move/Copy) to refine the sketch geometry

![image](https://user-images.githubusercontent.com/113594316/198826244-f377f387-16af-4f89-a57d-1808083ce178.png)

## STEP-5: 
  Select Measure (shortcut I) from the Inspect menu to verify all dimensions and geometric constraints of the sketch.

![image](https://user-images.githubusercontent.com/113594316/198826250-0e2f4985-18d7-4a07-8b1e-9c9fab11ea41.png)

## STEP-6: 
   Click the green Finish Sketch icon on the top-right toolbar to exit the sketch environment and finalize the 2D profile.

![image](https://user-images.githubusercontent.com/113594316/198826257-ccfcfd0c-040a-459e-bb9f-93c375f9177f.png)

## STEP-7: 
   Switch to the Solid tab, open the Create menu, and select Extrude (shortcut E) to convert the closed 2D sketch into a 3D solid body by specifying the depth.

![image](https://user-images.githubusercontent.com/113594316/198826270-d55912b8-0a02-4b36-acb2-02e9b4b328fd.png)

## STEP-8: 
    Alternatively, select Revolve from the Solid > Create menu, choose the closed profile and axis of revolution, and rotate it by 360° to generate an axisymmetric 3D solid model.

 
 ![image](https://user-images.githubusercontent.com/113594316/198826282-7a4844a8-0cb2-4573-8940-9a60356b7d04.png)
